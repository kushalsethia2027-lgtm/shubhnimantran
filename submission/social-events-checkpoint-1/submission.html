Nimantran — Product job specification

Product

Nimantran is an adults-only platform for discovering and hosting interest-led social gatherings across Delhi NCR. Its personality is contemporary, desi and Bollywood-inspired, with a simple choice between finding a gathering and hosting one.

Job to be done

When I want to meet people or make plans, help me find a nearby gathering that fits my interests, budget and comfort level, understand what is included, introduce myself to the host and receive clear confirmation before attending.

For hosts: help me describe a gathering, communicate its inclusions and rules, review introductions, approve guests within capacity and manage attendance.

Intended users

• Adults aged 18 and over who want new social experiences, including solo attendees and people new to the city.

• Independent organisers, activity hosts and venue operators bringing people together around shared interests.

Core experience

1. Browse by category, city, date, budget, age eligibility, atmosphere and sober/solo-friendly preferences.

2. Read the event description, price, inclusions, house rules and host information.

3. Sign in with Google, complete an adult profile and send an introduction with a join request.

4. The host reviews the request and approves or declines it. Free-event approval produces a confirmed booking.

5. The guest receives a category-themed invitation and access to the private venue details.

6. The host checks in the guest; after the event ends, checked-in attendees may review it.

Design and engineering requirements

Use a responsive, accessible interface with illustrated category collections, readable event information, simple forms, useful error/empty states and a list/map discovery toggle. Hosting uses one event date and start/end times in IST, including overnight end times. Store shared records in Supabase PostgreSQL and enforce ownership, capacity and private-address access in the backend.

Scope boundary

This release supports the free-event journey after Supabase setup. Paid checkout, host payouts and the proposed referral credits are not active. Do not describe a pending request as a confirmed ticket, invent attendance/reviews, or present illustrative events as real listings.

Acceptance criteria

A host can publish a valid event; a separate adult account can request a place; only that host can approve; confirmed bookings respect capacity; only authorised users can access private addresses; confirmed guests can download their invitations; only checked-in attendees can review after the event ends.

Current verification status

The latest code has passed 73 unit tests, type checks, static/full builds, and browser HTTP-fixture journeys including Google OAuth and host/guest booking flows. Database access checks passed during implementation. These are local checks, not a claim that a real hosted Google login or cross-device booking has passed. The owner last reported the Supabase project as paused; it must be resumed and the hosted flow verified for reviewer access. Checkpoint approval is determined by the submission platform, not by this document.

Nimantran — Feature list

Attendee experience

• Separate Find your scene and Host a gathering entry points.

• Six illustrated categories: Naach Meri Jaan, Khel Khel Mein, Daawat Hai!, Rang Jamao, Chalo Niklein and Hello Ji!.

• Search by event text, neighbourhood and host name.

• Filters for category, city, date, budget, age eligibility, atmosphere, language, daytime/evening, sober preference, solo-friendliness, available places and host rating.

• Today, this weekend and next-seven-days shortcuts.

• Sorting by upcoming date, lowest price, confirmed attendance or host rating.

• List/map switch with approximate event pins and map attribution.

• Event descriptions, inclusions, extra costs, rules, cancellation terms and host history/reviews.

• Google sign-in, adult profile and private birth date.

• Personal introduction and host approval before confirmation.

• Saved events and personal booking status dashboard.

• Confirmed category-themed invitation, SVG download and print/PDF support.

• Private exact venue details for confirmed guests.

• Booking cancellation and issue-report submission.

• Attendance-backed reviews after an event ends.

Host experience

• Three-part form: the idea, the details and the welcome.

• One event date with start/end times in IST; earlier end times finish the next morning.

• Category, atmosphere, adult age range, capacity, price and solo-friendly/sober settings.

• Explicit food, drink and other inclusions, extra costs, accessibility and house rules.

• Private venue address plus a public approximate neighbourhood pin.

• Browser-tab draft preservation and editable defaults.

• Published-event dashboard and guest introductions for review.

• Approval/decline actions, capacity enforcement and attendee check-in codes.

• Descriptive edits before active guest requests, with stale-edit protection.

• Event cancellation and replies to attendee reviews.

Trust, data and presentation

• Shared Supabase persistence and database-enforced permissions.

• Private dates of birth, venue details and booking codes.

• Guest counts and host reviews based on stored records.

• Adults-only accounts; additional event age rules apply. Age is self-declared, not independently verified.

• Responsive desktop/mobile design, accessible controls and reduced-motion support.

• Original AI-generated Bollywood-style category illustrations, used as artwork rather than proof of actual performers or customer activity.

• Production discovery contains only published host records; no fictional inventory or attendance counters.

Pending / unavailable

• Paid checkout, refunds and host payouts: not active.

• Proposed referral benefit of ₹250 each: not active; no credit has been issued.

• Chat, automatic messaging, paid boosts and subscriptions: outside this MVP.

• Reports are stored for operator review; a staffed moderation/support operation still needs to be established.

• Hosted Google login and real cross-device acceptance remain to be verified after the Supabase project is resumed and the social migration is installed.
